<summary><b>&#9654; ShieldJob &mdash; AI-Powered Fake Job &amp; Internship Detection</b></summary>

<br/>

A browser extension that flags fraudulent job and internship postings in real time, so students don't lose money or documents to scam listings.

```
  browser extension              FastAPI service                model layer
 ┌──────────────────┐         ┌──────────────────┐         ┌──────────────────┐
 │  DOM scraper     │  POST   │  /v1/classify    │         │  BERT classifier │
 │  overlay badge   │ ──────► │  request hashing │ ──────► │  fine-tuned on   │
 │  reason panel    │ ◄────── │  Redis cache     │ ◄────── │  posting corpus  │
 └──────────────────┘  verdict└──────────────────┘  logits └──────────────────┘
                              cache hit ─► skip inference
```

| Aspect | Detail |
| :-- | :-- |
| **Stack** | Python &middot; BERT &middot; FastAPI &middot; Redis &middot; Browser Extension APIs |
| **Scale** | Real-time inference on live job listings as the user browses |
| **Impact** | Explainable predictions — users see *why* a posting was flagged, not just a score |
| **Repo** | [github.com/AkashGowdaNC](https://github.com/AkashGowdaNC?tab=repositories) |

**My contribution:** built the detection pipeline end to end — integrated a BERT classifier behind a FastAPI service, added Redis caching so the model runs once per unique listing instead of once per view, and surfaced explainability signals in the extension UI so the verdict is auditable.
